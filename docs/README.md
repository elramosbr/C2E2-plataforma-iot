# IoT Energy Platform

Plataforma integrada IoT para monitoramento e otimização do consumo energético utilizando:

- ESP32-S3
- LoRa SX1262
- MQTT
- FastAPI
- PostgreSQL / TimescaleDB
- Grafana
- Flutter

## Architecture

Nós Sensores -> LoRa -> Gateway -> MQTT -> Backend -> Dashboard
